## <h1>DOCUMENTO DE CONCEPTO	

*Autor:*	
- Eric Dumortier

### <h2>1 - Introducción

*Titulo:*
- Galaxy Heroes

*Concepto:*	
- Juego de naves espaciales con scroll lateral en 2D

*Genero:*
- Shot'em up 

*Público Objetivo:*
- Jugadores que disfrutan juegos dinámicos con momentos de pausa para observar diálogos
- Público adolescente y adulto

*Plataforma:*	
- Windows, Mac y Linux

*Motor de Videojuegos:*
- Godot

*Versión del editor:*
- 4.6
  
### <h2>2 – Jugabilidad

*Controles:*	
- Mouse, teclado y joystick

*Mecánica Central:*
- Controlar la nave del jugador, esquivar ataques y eliminar enemigos.
 
*Elementos Únicos del Gameplay:*
- Sistema de diálogos
- Recolección de power up
- Mejoras de municiones
- Elección de distintos personajes principales
   
*Meta de Diseño:*	
- Equilibrar patrones de ataques enemigo con la dificultad adecuada

*Game Loop*
<br/>
- menu principal (Start - Continue - Options - credits - Exit)
- Selección de personaje
- Nivel 1
- Mejora munición
- Nivel 2
- Mejora munición
- Nivel 3
